## 🔬 Core AI Domains & Architectural Specializations

### 1. 🎙️ Real-Time Telephony & Speech AI
- **Low-Latency Streaming:** 8kHz to 16kHz audio upsampling pipelines with user-turn coalescing over Twilio SIP trunks.
- **Synthesized Dialogue & Multilingual Voice:** Integrated Sarvam AI, ElevenLabs, and Deepgram Nova-3 across 15 Indian languages.
- **Dual-Layer Guardrails:** Pre-inference sub-10ms deterministic regex filters combined with runtime semantic boundary checks neutralizing 100% of prompt injections across 5,000+ benchmark tests.

### 2. 🤖 Autonomous Multi-Agent Orchestration & Tool Calling
- **Model Context Protocol (MCP):** Dynamic schema registration and function catalog verification over SSE and streamable HTTP transports across 25+ platform routes.
- **Agent Loops & Graph Workflows:** Directed cyclic and acyclic agent graphs built with LangGraph and CrewAI for autonomous bug triaging, PR code reviews, and next-best actions.
- **Zero-Trust AST Validation:** Enforcing code verification across 50+ AST nodes on disk before allowing agent-generated suggestions to reach production repositories.

### 3. 📈 Scientific Machine Learning (SciML) & Dynamical Systems
- **Sparse Dynamics Identification (SINDy):** Symbolic differential equation discovery using Sequential Thresholded Least Squares (STLSQ), uncovering mechanistic equations from empirical epidemiological time-series data.
- **Mechanistic ODE Modeling:** Harmonically-forced seasonal SEIRS systems that prevent long-term simulation decay and outperform standard non-mechanistic deep learning baselines by 47.6% RMSE.

### 4. 👁️ Medical Computer Vision & Explainability
- **Multimodal Architectures:** 3-branch PyTorch convolutional networks processing fundus, optic disc, and optic cup representations concurrently.
- **Clinical Interpretability:** Pixel-level feature attribution via Grad-CAM saliency maps and SHAP value matrices to provide clinical validation for diagnostic predictions.

### 5. 🔍 Citation-Grounded RAG & Ingestion Engines
- **Hybrid Retrieval:** Dense + sparse vector indexing across FAISS and ChromaDB with cross-encoder reranking.
- **Local Small Language Models:** Inference with local Gemma 3 ensuring privacy and deterministic adherence to source citations.
- **Structured Schema Synthesis:** Transforming unstructured medical claim documents into standardized HL7 FHIR R4 JSON resources.
